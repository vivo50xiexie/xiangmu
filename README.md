# 股票辅助网站（A 股 沪深）

一个 Flask 小站：输入 6 位代码或股票名称，看 **实时行情 + 近 3 年 K线/折线 + 公司大事（带股价涨跌标注）**，还能 **模拟炒股**。

纯 Python 写，不依赖任何付费接口。行情/K线来自腾讯财经公开接口，新闻来自东财搜索/搜狗/今日头条，代码-名称全表来自 AkShare / 东财直连。

## 功能

- 🔍 搜索框支持 **6 位代码 / 股票名称**，输入即出**自动补全建议**（名称前缀 + 代码前缀匹配），全市场代码表三层降级保证名称搜索稳定
- 📊 个股页：实时行情卡（含总市值 / 市盈率 / 市净率 / 换手率）+ 近 3 年走势（K线 / 折线可切换，ECharts 渲染，前复权）
  - **MA5/20/60/120 均线叠加、MACD 副图**（本地计算）
  - 缩放视窗实时**区间统计**：区间涨跌、最高最低、振幅、日均量
- 📰 公司大事：多源新闻采集（东财搜索 + 搜狗 + 今日头条），自动分 7 类（人事 / 财报 / 战略 / 产品 / 资本 / 政策 / 动态），标注媒体来源
  - **每条新闻标注发布当日股价徽章** `▲上升 / ▼下降`（事件研究法：事件日收盘 vs 前一交易日收盘），并给出**事件后 1 / 3 / 5 / 20 日累计涨跌幅**
  - 排序按钮（时间 / 类型 / 涨幅 / 跌幅）+ 类别筛选 + 展开收起，全部即时完成
- ⭐ **自选股**：个股页一键收藏（本地 JSON），首页实时刷新现价与涨跌幅
- ⬇ **CSV 导出**：K 线（近 3 月 / 1 年 / 3 年）、新闻（含事件后涨跌幅列）、模拟盘成交记录，UTF-8 BOM 兼容 Excel
- 📌 首页「今日热点榜」：60 只热门股实时计算，四个子榜（涨幅 / 跌幅 / 成交额 / 换手率）各取前 10，tab 切换 + 独立滚动
- 📖 股票字典：全市场 5500+ 只按拼音首字母 A-Z 分组，支持键盘 A-Z 快速跳转
- 📈 模拟炒股：初始 10 万资金，数据存本地 JSON，重启不丢
  - A 股规则：整手交易、**T+1**（当日买入次日可售）、涨跌停限价校验（主板 ±10%，创业板 / 科创板 ±20%）
  - 真实费用：佣金万 2.5（最低 5 元）+ 印花税 0.05%（卖出）+ 过户费 0.001%
  - 下单指导价自动获取、可买 / 可卖提示、费用预估；持仓按实时价刷新浮动盈亏；对账单 + 一键重置
- ⌨ 任意页面按 `/` 聚焦搜索框；⚡ 服务端 TTL 缓存，减少上游接口请求

## 本地运行

需要 Python 3.10+。

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动
python stock.py

# 3. 浏览器打开
http://127.0.0.1:5000
```

Windows 用户也可以直接双击 `start.bat`。

## 部署给别人访问（Railway 示例）

这个服务是普通 Flask 应用，任何能跑 Python 的平台都能部署。以 [Railway](https://railway.com) 为例：

1. 把本仓库推送到 GitHub
2. Railway 注册 → New Project → Deploy from GitHub repo
3. Railway 会自动执行 `pip install -r requirements.txt`，设置环境变量：
   - `HOST=0.0.0.0`（代码已支持，见下方说明）
   - `PORT`（Railway 自动注入）
   - 启动命令：`python stock.py`
4. 给服务添加 Public Networking，拿到 `xxx.up.railway.app` 域名

### 监听端口

代码默认监听 `127.0.0.1:5000`，可通过环境变量覆盖：

```bash
HOST=0.0.0.0 PORT=8080 python stock.py
```

## 数据来源与限制

| 数据 | 来源 | 限制 |
|------|------|------|
| 实时行情 / K线 / 股票名称 | 腾讯财经 `qt.gtimg.cn` / `web.ifzq.gtimg.cn` | 公开接口，无鉴权；K线支持前复权 |
| 公司新闻 | 东财搜索 API + 搜狗新闻 + 今日头条移动搜索 | 东财搜索只保留近 6 个月全文；头条/搜狗按关键词搜索 |
| 代码-名称全表 | AkShare `stock_info_a_code_name()` | 首次拉取约 3-5 秒，缓存 1 小时 |
| 字典页拼音 | 本地 `pypinyin` | 无外部依赖 |
| 热点榜 | 腾讯批量行情（60 只硬编码热门股池） | 不是全市场，只在池内排名 |

**非交易时段**（夜间 / 周末 / 节假日）实时行情会返回空，网站会用 K线最后一根 bar 推导昨收/今开作为降级，所以页面不会白屏。

## 目录结构

```
stock.py             # 主程序（Flask app + 数据抓取 + 路由 + 自选/导出/事件标注）
simdata.py           # 模拟炒股数据层（JSON 持久化 + A股交易规则 + 费用模型）
start.bat            # Windows 一键启动（纯 ASCII，无乱码问题）
requirements.txt     # 依赖清单
README.md            # 本文件
CHANGELOG.md         # 更新日志
LICENSE              # MIT
sim_data.json        # 模拟盘数据（首次交易后自动生成，不进版本库）
watchlist.json       # 自选股列表（加入自选后自动生成，不进版本库）
templates/
  index.html         # 首页（搜索 + 自选面板 + 模拟盘卡片 + 热点榜 + 字典入口）
  result.html        # 个股结果页（行情卡 + 图表/均线/MACD + 公司大事/排序筛选 + 自选/导出/模拟买卖）
  dict.html          # 字典页（A-Z 分组）
  sim.html           # 模拟交易页（下单 + 费用预估 + 实时持仓盈亏 + 资产概览）
  statements.html    # 对账单（含手续费/本笔盈亏 + CSV 导出）
```

## 已知问题 / 可改进

- 热点榜股票池是硬编码的 60 只，可改成动态拉全市场排行
- 新闻分类是关键词规则，偶尔误判（如"回购"出现在标题但实际是"机构回购评级"），可换 LLM 分类
- 盘后发布的新闻仍标注当日涨跌（同主流行情软件口径）；如按"下一交易日"归因需另行调整
- 字典页 5500+ 只全量渲染，首屏较重；可改成按需加载
- 未做多用户系统（自选/模拟盘均为本地单账户）
